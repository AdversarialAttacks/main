# Robustified Models

Hier in diesem Ordner befinden sich die robustifizierten Modelle. 

Dabei ist ein Ordner wie folgt zu verstehen: 

`<model-name>-<datensatz>-<n-trainingsbilder>-<robustifikationsstufe>`

- `<model-name>`: Name des Modells bspw. ResNet50
- `<datensatz>`: Name des Datensatzes bspw. mri_data oder covidx_data
- `<n-trainingsbilder>`: Anzahl der Trainingsbilder die für die Generierung der UAPs verwendet wurden 
- `<robustifikationsstufe>`: Stufe der Robustifikation bspw. 1 oder 2

daraus resultiert ein Ordner mit dem Namen: `resnet50-covidx_data-n_200-robustification_0`

# Models

Dieser Ordner beinhaltet alle Modelle die für die Anwendung benötigt werden. Die Modelle sind auf [Weights & Biases](https://wandb.ai/24FS_I4DS27/baselines) als Artefakte gespeichert und können von dort heruntergeladen werden.

Das Python Script [download.py](../src/utils/download.py) beinhaltet die Funktion `download_models`, mit der man die vortrainierten Modelle von Weights & Biases herunterladen kann. 

Als Beispiel wird im Notebook [06-perturbation-example.ipynb](../notebooks/06-perturbation-example.ipynb) die Funktion verwendet.

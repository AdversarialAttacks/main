# Notebooks

Hier in diesem Ordner befinden sich die Jupyter Notebooks, die für die Bearbeitung unserer Thesis verwendet wurden. Die Notebooks verwenden eigens entwickelte Python-Module, die sich im Ordner `src` befinden.

Eine kurze Übersicht über die Notebooks:

| Notebook | Beschreibung |
| --- | --- |
| [00-eda.ipynb](00-eda.ipynb) | Explorative Datenanalyse von den Daten |
| [01-dataloader.ipynb](01-dataloader.ipynb) | Dataloader von den Daten |
| [02-models.ipynb](02-models.ipynb) | Klassen Testen für dynmaisches Modell |
| [03-training.ipynb](03-training.ipynb) | Training aller Modelle |
| [04-evaluation.ipynb](04-evaluation.ipynb) | Evaluierung der Modelle durch Trainings- und Validierungsdatensatz |
| [05-testing.ipynb](05-testing.ipynb) | Evaluierung der Modelle durch den Testdatensatz |
| [06-perturbation-example.ipynb](06-perturbation-example.ipynb) | Erste Generierung einer UAP |
| [07-customtransform-testing.ipynb](07-customtransform-testing.ipynb) | Testen einer Custom PyTorch Transforms Preprocessor |
| [08-eval-uap-examples.ipynb](08-eval-uap-examples.ipynb) | Evaluierung der UAPs |
| [09-pipeline.ipynb](09-pipeline.ipynb) | Pipeline für Adversarial Attack mit UAP sowie Robustifizierung |
| [10-UAP.ipynb](10-UAP.ipynb) | Visualisierung der UAPs |
| [11-metrics.ipynb](11-metrics.ipynb) | Berechnung der Metriken |
| [12-diff-test-val.ipynb](12-diff-test-val.ipynb) | Untersuchung der Unterschiede zwischen Test- und Validierungsdatensatz |
